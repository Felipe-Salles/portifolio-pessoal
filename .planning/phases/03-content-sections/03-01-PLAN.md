## Phase Goal

ROADMAP Phase 3's `**Goal:**` line is not written in the three-slot user-story form, so it is quoted verbatim here rather than restated as an invented story (same handling as Phase 2's plans — see the note in `02-03-PLAN.md`):

> Visitor can read every core section of the portfolio — Hero, Dossier, Tech Stack, Projects, Contact — matching the prototype's visual design and reflowing correctly on mobile.

This plan delivers the first vertical slice of that goal: the page container plus the two sections that answer "who is this person" — Hero and Dossier.

<objective>
Replace `src/pages/index.astro`'s Phase 1 pipeline-proof scaffolding with the first two real content sections, and give `<main>` the horizontal margin / max-width / section-rhythm wrapper every section depends on.

Purpose: This is the first plan in the project that produces page content a visitor actually reads. It also establishes the `<main>` container that all five sections sit inside, so the three later plans in this phase can append a section and nothing else. Deleting the scaffolding token gallery removes the only markup that exercised several of Phase 1's representative design-token utilities, so this plan also adapts that gate to keep proving the same thing against real markup.
Output: `scripts/verify-sections.mjs` (new Phase 3 gate), a wrapped `<main>` in `Base.astro`, and a `src/pages/index.astro` containing the Hero and Dossier sections.
</objective>
