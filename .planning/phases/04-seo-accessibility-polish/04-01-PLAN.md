## Phase Goal

**As a** technical recruiter (or a search-engine crawler), **I want to** find this portfolio in search, see a proper preview when its link is shared, and navigate it without accessibility barriers, **so that** the site earns technical trust before a single project description is read.

This plan delivers the first slice of that story: the site becomes *identifiable* — crawlable, correctly titled/described, branded in the browser tab, and free of decorative noise in the accessibility tree.

<objective>
Provision this phase's toolchain, set the `site` URL every absolute URL in the project depends on, and ship the three "identity" artifacts a visitor or crawler meets before any content: `robots.txt` + `sitemap.xml`, the `>_` favicon set, and `Base.astro`'s full `<head>` metadata contract. Also lands the D-11/D-12 `aria-hidden` pass on the four decorative elements already rendered by Phase 3.

Purpose: SEO-01/03/04/05 and A11Y-03's markup half. Every later plan in this phase (OG image, 404 page, both verification gates) depends on `site` being set, the head contract existing, and Playwright/axe being installed.
Output: `astro.config.mjs` with `site` + sitemap, `public/robots.txt`, three favicon assets + their generator, extended `Base.astro` head, `metaDescription` in `site.ts`, `aria-hidden` on 4 decorative elements, and a narrowed SEC-01 gate that tolerates `rel="canonical"`.
</objective>
