## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local working tree → public GitHub repo | Once pushed, every tracked file is permanently public if the repo is public; this is irreversible in practice |
| GitHub push → Vercel production build | A webhook grants a remote build environment the ability to run this repo's scripts with network access |
| Vercel edge → visitor browser | The only place SEC-02/SEC-03 are actually enforced; every earlier assertion was a declaration |
| `astro.config.mjs` `site:` → every absolute URL the site emits | A wrong origin here silently mis-points canonical, Open Graph and sitemap URLs across the whole site |
