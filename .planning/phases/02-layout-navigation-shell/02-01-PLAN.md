## Phase Goal

ROADMAP Phase 2 goal, quoted verbatim (it is not written in the three-slot `As a / I want to / so that` form; it is not restated here as an invented user story):

> Visitor loads any page and sees the correct site shell — navigation, footer, and page metadata — matching the design system, in Portuguese, and fully keyboard-accessible.

This plan delivers the first vertical slice of that goal: a real page shell that renders and is keyboard-operable end to end.

<objective>
Turn the Phase 1 scaffolding page into a real site shell: a fixed nav bar with the brand wordmark, the four section links, and a live Connect anchor; a skip link as the first focusable element; semantic `<nav>` and `<main id="main-content">` landmarks; and a global cyan `:focus-visible` glow. Lock all of it behind a deterministic `dist/` gate, written first so it starts RED.

Purpose: This is the slice a visitor actually experiences — after it lands, someone can load the site, see navigation, and traverse the whole shell with the keyboard alone with visible focus at every stop. It also closes SEO-06 with an assertion instead of an assumption, and establishes the `<main id="main-content">` landmark that Phase 3's sections will slot into.
Output: `src/components/Nav.astro`, an extended `src/layouts/Base.astro`, two new CSS primitives, and a passing `npm run verify:shell`.
</objective>
